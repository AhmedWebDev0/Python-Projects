# 🎮 Word Duel

A simple Python word game for two players.

## 📖 About

**Word Duel** is a terminal-based game where two players enter a word using the available letters (`A` to `J`). Each letter has a predefined score, and the player with the highest total score wins.

This project was created to practice Python fundamentals such as loops, dictionaries, input validation, and working with external libraries.

## ✨ Features

* 👥 Two-player mode
* 🔤 Letter scoring system
* ✅ Input validation
* 🎨 Colored terminal output using `termcolor`
* 🖼️ ASCII art using `pyfiglet`

## 🛠️ Technologies

* Python 3
* pyfiglet
* termcolor

## 📦 Installation

Install the required libraries:

```bash
pip install pyfiglet termcolor
```

## ▶️ Run

```bash
python main.py
```
