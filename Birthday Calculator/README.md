# 🎂 Birthday Calculator

A simple Python project that calculates the time difference between a user's birthday and the current date.

## 📖 About

This project asks the user to enter their birth year, month, and day. It then uses Python's built-in `datetime` module to calculate the difference between the birthday and today's date.

The project was created to practice working with dates, user input, and Python's `datetime` library.

## ✨ Features

* 📅 Enter birth year, month, and day
* ⏳ Calculate the time difference from the birthday to today
* 🐍 Uses Python's built-in `datetime` module
* 💻 Simple terminal-based application

## 🛠️ Technologies

* Python 3
* datetime
