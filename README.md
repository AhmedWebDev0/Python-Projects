# 🖼️ Image Manipulation with Pillow

A simple Python project for practicing basic image manipulation using the **Pillow** library.

## 📌 What I Learned

In this project, I practiced:

* Opening an image using `Image.open()`
* Getting image dimensions using `.size`
* Cropping images using `.crop()`
* Saving images using `.save()`
* Displaying images using `.show()`
* Working with image coordinates: `(left, top, right, bottom)`

## 🛠️ Technologies

* Python
* Pillow

## 📦 Installation

Install Pillow using:

```bash
pip install Pillow
```

## ▶️ How to Run

Run the Python file:

```bash
python Image_Manipulation_With_Pillow.py
```

The program asks for the path of an image, then splits the image into two parts:

* Left half
* Right half

The two parts are then saved as separate image files.
